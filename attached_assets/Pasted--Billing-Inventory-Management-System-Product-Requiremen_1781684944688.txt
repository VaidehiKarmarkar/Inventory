




Billing & Inventory Management System – Product Requirement Document (PRD)

1. Project Overview

Project Name

Billing & Inventory Management System

Objective

Develop a web-based billing and inventory management application that allows administrators to manage products, inventory, users, and customer orders while generating professional invoices.

Technology Stack

* Frontend: React.js
* Backend: Node.js + Express.js
* Database: Any 
* PDF Generation: PDF download functionality
* Email: Mock email functionality (No actual email integration in Phase 1)

⸻

2. User Roles

Admin

1. Dashboard
2. Product Repository Management
3. Inventory Management
4. Create Orders
5. Order History

User

User will have access to:

1. Create Orders
2. View Own Created Orders
3. Download Invoice

* Product Management

6. Inventory Management Module

Purpose

Maintain stock movement.

Inventory Table

Field	Type
Inventory ID	Auto Generated
Product ID	Reference
Product Name	Text
Previous Quantity	Integer
Quantity Added	Integer
Quantity Reduced	Integer
Current Quantity	Integer
Action Type	Add/Reduce
Updated By	User ID
Updated Date	Timestamp

Business Logic

When Product Added:
Current Quantity = Previous Quantity + Added Quantity

When Order Created:
Current Quantity = Previous Quantity - Ordered Quantity

System must:

* Prevent negative inventory
* Show out-of-stock warning
* Alert when stock < 10 units

Invoice Calculation

Fields

Field	Type
Subtotal	Calculated
GST Percentage	Input
GST Amount	Calculated
Referral Charges	Input
Discount	Optional
Grand Total	Calculated

Formula

Subtotal = Sum(Product Total)
GST Amount = Subtotal × GST %
Grand Total = Subtotal + GST Amount + Referral Charges - Discount
